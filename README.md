# Trade-time / Trading Sessions

Android trading-session notification and hourly alarm app.

## Included
- Previous Event → Next Event → Remaining to Next in the persistent notification.
- Green / Yellow / Red status based on the configured trading windows.
- Settings screen with Persian/English switch.
- Start/Stop persistent notification in Settings.
- Event notification switch.
- 24 separately configurable hourly alarms.
- Separate ON/OFF switch and horizontal sound button for every hour.
- Per-hour comments/notes, shown in the alarm notification.
- App icon and About page.
- Version 1.2 and Msp rights notice.
- Re-schedules alarms after reboot/update.

## Build on GitHub
Open **Actions → Build Trade-time APK → Run workflow**. The APK is uploaded as an artifact.
